# Tulas International School — Homepage Redesign

A modern, responsive and animated homepage redesign for Tulas International School.

## Tech Stack

- React
- Vite
- Framer Motion
- Lucide React
- CSS

## Features

- Responsive design
- Animated hero section
- Scroll-triggered animations
- Custom cursor
- Scroll progress indicator
- Light/Dark theme
- Mobile navigation
- Responsive layouts
